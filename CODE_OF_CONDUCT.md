# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith. Criticise code, not
people.

## What's not welcome

Harassment, personal attacks, discriminatory language, or sustained disruption
of discussions. Posting someone else's private information — including phone
numbers or message contents belonging to real recipients — is not acceptable
here, and in this project it's also a privacy problem for people who never
agreed to be part of it.

## Scope

This applies to issues, pull requests, discussions, and any other space where
the project is being worked on.

## Enforcement

I maintain this project alone. If something crosses the line, report it
privately through the repository's Security tab (it creates a private thread)
or by contacting me through my GitHub profile.

I'll read it and act — usually by editing or deleting the content, and blocking
the account if it continues. I won't discuss individual moderation decisions in
public threads.

This isn't a large community with a committee; it's one person trying to keep a
useful project pleasant to be around.
